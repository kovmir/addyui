# AGENTS.md

Guidance for AI coding agents working on addyui, a terminal UI for
addy.io built with Bubble Tea v2.

## Project layout

- `cmd/addyui/` — the TUI binary entry point.
- `cmd/mockaddy/` — standalone binary serving a fake addy.io API.
- `internal/tui/` — application model; `views/` holds one file per screen
  (alias list/details, recipient list/details, create, help, routing).
- `internal/api/` — addy.io API client.
- `internal/config/` — configuration from flags/environment.
- `internal/mockaddy/` — in-memory fake API server shared by the demo
  binary and the test suite.

## Generated code — do not edit by hand

`internal/api/gen.go` is generated by oapi-codegen from
`internal/api/openapi.yaml` (config: `internal/api/oapi.cfg.yaml`).
To change API types, edit `openapi.yaml` and regenerate:

    go generate ./internal/api

Never hand-edit `gen.go` beyond what regeneration produces.

## Build, test, verify

- `make build` — build the TUI binary.
- `make test` — run all tests with `-race`.
- `make vet` / `make fmt` — vet; list non-gofmt'd files.
- `make check` — test + vet; this is what CI runs, so run it before
  declaring work done.

Formatting is plain `gofmt`. Tests use the standard library only
(`net/http/httptest` + `internal/mockaddy`), no external test
frameworks or assertion libraries.

## Testing against the API — never hit real addy.io

Do not make requests to the real addy.io service. Use the fake server:

- In tests: `httptest.NewServer(mockaddy.New(...))` with `With*` options.
- Manually: `go run ./cmd/mockaddy`, then
  `ADDY_BASE_URL=http://127.0.0.1:18099 ADDY_API_KEY=demo ./addyui`.

`ADDY_API_KEY` is a real credential if set in the environment; never
commit one or write one into code, tests, or docs.

## TUI conventions

- Bubble Tea v2 / Lip Gloss v2 / Bubbles v2 (charm.land imports).
- One file per view in `internal/tui/views/`; screens are wired
  together in `routing.go`; shared helpers in `helpers.go`.
- User-facing keybindings must be reflected in the in-app help view
  (`help.go`, shown on `F1`).
